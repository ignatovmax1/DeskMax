# Аудит DeskMax 0.3.0 — 1 октября 2026

## Реализовано

- Windows → Windows: JPEG-трансляция основного монитора, мышь, прокрутка, клавиатура.
- Явное подтверждение владельца с именем/ID участника, видимое окно трансляции, остановка кнопкой и Ctrl+Alt+F12.
- Один сеанс в интерфейсе, отдельное окно зрителя с отключением управления и корректной геометрией при чёрных полях.
- Обычный запрос действует 2 минуты, разрешённый сеанс до 1 часа. Отзыв, остановка, истечение и разрыв закрывают обоих участников.
- До 1600 пикселей по длинной стороне, до 5 кадров/с. GDI-объекты освобождаются; очереди кадров и команд ограничены.
- Удерживаемые удалённо клавиши/кнопки отпускаются при потере фокуса зрителя и завершении соединения. Остановка синхронизирована с применением ввода.
- Авторизация первым сообщением WebSocket без секретов в URL; роль проверяется, повторный сокет отклоняется. Доступ проверяется перед каждой пересылкой и периодически.
- Heartbeat каждые 5 секунд; клиент закрывает соединение без сообщений 20 секунд. JPEG ограничен 2 МиБ, ввод 4 КиБ; размеры JPEG проверяются до декодирования.
- Версия 0.3.0, Stable / GitHub Releases, автоматическая проверка, подтверждение установки и SHA-256.

## Подтверждённые проверки

- Release-сборка: 0 ошибок, 0 предупреждений; самостоятельный Windows EXE собран.
- 27 серверных/протокольных тестов, включая обновления и геометрию, прошли. Используется настоящий TCP WebSocket.
- Подтверждены запрет транспорта до согласия и для постороннего, повторный сокет, отзыв, остановка, неверный ключ, повреждённый JSON, превышение размера и неверный тип сообщения. Проверки требуют реального закрытия сокета; heartbeat не считается закрытием.
- Windows smoke: 11 проверок прошли. JPEG 1600×900 содержит видимую цветную область; 25 захватов сохранили число GDI-дескрипторов 20 → 20.
- SendInput доставил символ в собственный TextBox; ReleaseAll отпустил удерживаемую клавишу; координаты мыши совпали с физическими.
- Два RemoteConnection через локальный сервер передали настоящий JPEG рабочего стола, клавиатуру, левый клик и wheel delta 120. После отключения зрителя клавиша владельца отпустилась. XAML окон владельца и зрителя инициализирован.
- Публичный HTTPS/WSS: TLS проверен обычным клиентом; роли, ready, синтетический двоичный кадр, клавиатурная команда и аутентифицированная остановка прошли через Nginx. Настоящий JPEG и Windows-ввод проверены локально, а не на двух физических машинах через интернет.

## Ограничения

- Основной монитор, без звука, файлов, буфера обмена и Android-клиента.
- HTTPS/WSS защищает соединение до сервера; сквозного шифрования между участниками нет.
- Нет постоянной БД, аккаунтов/2FA, постоянного ID и защищённого сохранения клиентского секрета. UI-журнал хранится до закрытия; постоянного серверного аудита нет.
- Trusted grants существуют в API, но Windows-клиент не предоставляет фоновый доступ без владельца и не запускает скрытую трансляцию.
- UAC, приложения с более высокими правами и Ctrl+Alt+Delete не поддерживаются.
- Матрица DPI/мультимониторных конфигураций, длительная нагрузка, нестабильные реальные сети и две отдельные физические машины не проверялись.
- Коллизия шестизначного кода безопасно отклоняется; для масштабирования нужен запрос по ID и коду. Регистрации пока не ограничены отдельной квотой.
- Authenticode-подписи нет; SHA-256 проверяет целостность относительно опубликованного GitHub-релиза.
